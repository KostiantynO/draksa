# Draksa MeowAloud

> Draksa is a naga-girl, feed her, and she will meow :3

She helps me a lot!

I use her when ever I want to read text or code aloud - from CatGPT, Grokitty and Gemini
(they don't read code).

She is a polyGlotka :D And can speak in different languages, provided by browser Gods 🧙‍♂️

## Pros:

- In-browser TTS
- Read code without annoying parts
- Recognizes cat-faces :3
- Simple TTS. Just a tool (no ai)
- Change voice mid sentence :D
  - The catch: Text is the same :D
- Off-line after load. No server. No network requests.
  - The catch: Full-online currently :D - because browser makes an internal
    `invisible to developer` (me) request (in Chrome - to Google) for `voices` on each
    load, why?

    Why I cannot load voices fully off-line and save them in a service worker?

    If request is made to browser provider, why can't we cache it?

    We need some simple good sounding libraries for offline.

    I would like to have that functionality for off-line use. That would be AMAZING to use
    Draksa fully-offline (without even internet or site-load, once you cached the
    app-shell in a service worker.)
- [Open-source](https://github.com/KostiantynO/draksa)

## Cons:

- No translation. Out of scope.
- No AI. Not a chat :D
- No beautiful voices from servers :D But I want them beautiful voices! :D
  - Nobody stops me from wanting thingies :D What differentiates is HAVING THEM :D

  But I need to count my blessings :D And say thank you for having Browser Voices :D

  Dear God, thank you for inspiring other smaller browser Gods 🧙‍♂️ to share their voices
  via speechSynthesis api! :)
